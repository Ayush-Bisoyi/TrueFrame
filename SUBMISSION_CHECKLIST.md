# Submission checklist

Before submitting the repository:

- [ ] Keep the GitHub repository private until the organizers allow public access.
- [ ] Add the mentor specified by the recruitment instructions as a collaborator.
- [ ] Add the deployed public URL to the submission form.
- [ ] Configure a real Sepolia RPC URL, testnet-only fee key, contract address, and public RPC URL.
- [ ] Make one real proof and save the verification URL.
- [ ] Verify the original file and a modified copy. Capture both results in a short screen recording.
- [ ] Show the transaction link and the ProofAnchored event in the block explorer.
- [ ] Check the browser Network panel while creating a proof: no video request should exist.
- [ ] Never commit .env, the fee key, the location salt, or a real private recording.
- [ ] Commit in meaningful stages rather than one huge final commit. Suggested messages: scaffold, protocol, capture UI, API anchor, verifier, tests and docs.

The included local mock mode is for development only. A reviewer should see LOCAL DEMO until the real contract and testnet environment are configured.
